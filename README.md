# 小咪小咪 · miaoMi

陪你把平凡的日子，过成有猫的日子。一个中文猫咪陪伴与养成小游戏。

## 启动浏览器体验版

需要 Node.js 22.18+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（通常为 `http://localhost:5173`），点击「领养第一只小咪」。可以选择品种、性别、名字和职业。性格随机且不向玩家显示，使用台词、互动偏好与随机事件表现。

Windows 也可以直接双击根目录的 `启动网页版.cmd`，它会启动 Vite 并打开浏览器。不要直接双击 `index.html`：该文件引用 Vue 单文件组件和 TypeScript 源码，需要 Vite 先编译，浏览器通过 `file://` 无法直接运行。

```bash
npm run build  # TypeScript 检查与生产构建
npm test       # 游戏规则测试
npm run test:ui # 保持 dev 服务运行，使用本机 Chrome 验证操作流程和响应式布局
npm run preview
```

## 目前可以体验

- 5 种猫咪外观、4 种隐藏性格、随机初始金币、最多 4 只猫的家庭。
- 喂食、添水、逗猫、梳毛、洗澡、抚摸、零食与装扮。照料冷却 30 秒，金币与库存实际扣减。
- 饱食、饮水、清洁、心情、精力和好感变化。离线最多结算 8 小时，好感损失每日封顶 6 点。离家前预警，外出后可免费找回。
- 工作、睡觉、放空、运动、看剧的陪伴计时。支持 1 分钟快速体验，完成后增加好感，刷新后可继续。
- 6 类随机事件，包括性格事件和多猫互动。首次事件约 90 秒后出现；首次偶遇约 150 秒后出现，在首页提示和消息入口查看。朋友、路边、邻居和领养站相遇可免费领养；街角售猫事件花费 20 游戏金币，均可拒绝。
- 程序员语法填空、作家主题创作、画家像素临摹。评分规则透明，完成赚取 10–40 游戏金币，同一回合不能重复领奖，领奖后休息 60 秒。
- 猫粮、零食、蝴蝶结、围巾和新猫咪购买；自动记录日记。
- 页面内喝水、伸展、远眺提醒，可关闭或调整间隔。浏览器自动存档、导出与导入。
- 适配桌面和手机尺寸；键盘操作、弹窗焦点限制与减少动态效果支持。

## 技术与目录

| 位置 | 用途 |
| --- | --- |
| `src/` | Vue 3 + TypeScript + Vite + Pinia 浏览器体验版 |
| `src/game/data.ts` | 猫咪、事件、商品、职业题库与评分素材 |
| `src/game/engine.ts` | 不依赖 DOM 的游戏规则、数值结算与存档校验 |
| `src/components/` | SVG 猫咪与房间、三种职业小游戏 |
| `tests/` | Node 内置测试，覆盖游戏状态与防重复结算 |
| `apps/miniapp/` | 使用 `.uvue` / `.uts` 的 uni-app x 小程序工程 |

界面使用自制 SVG、CSS 与 Lucide 图标，不依赖远程图片或字体。Element Plus 与管理后台路由不属于当前玩家界面的必要依赖，暂不引入。

### uni-app x 与微信端

**根目录的 Vite 应用是浏览器体验版，不是 uni-app x 编译器。** 真正的 x 工程放在 `apps/miniapp/`，用 HBuilderX 导入并运行到微信开发者工具。微信端具体功能与部署步骤见该目录说明。

DCloud 官方说明：uni-app x 使用 HBuilderX 创建工程，Web 编译基于 Vite；普通 `uni-preset-vue#vite` 模板属于普通 uni-app，不能替代 x 工程。x 支持编译为微信小程序，命令行自动化使用 HBuilderX CLI。

- [uni-app x 项目与编译](https://doc.dcloud.net.cn/uni-app-x/project)
- [uni-app x 工程化](https://doc.dcloud.net.cn/uni-app-x/worktile/)
- [编译到微信小程序](https://doc.dcloud.net.cn/uni-app-x/mp/index.html)

## 需要你准备的配置

本地体验不需要账号、数据库或密钥。要运行微信真机与云端服务，需要：

1. 安装 HBuilderX 与微信开发者工具。
2. 准备微信小程序 AppID，填入小程序工程的 `manifest.json`。
3. 在自己的 DCloud 账号中创建并关联 uniCloud 服务空间，按小程序目录说明部署数据库和云函数。
4. 按小程序目录说明配置并部署 `miao-auth`、`miao-session` 和 `miao-save`。AppSecret 与签名密钥只放在云端配置中，不要写入前端或 Git。

## 版本边界

Web 当前使用本地存档，尚未接入真实微信登录或云同步，也没有真实支付。金币是游戏内数值。作家评分依据篇幅和关键词，不是 AI 文学评审。提醒只在页面运行时显示，微信订阅消息需要配置模板、用户授权和后端定时任务。

当前浏览器数据可由用户自行修改，适合个人 demo。正式线上经济系统应由云端结算照料、交易、职业奖励与随机事件，校验身份、时间、幂等请求和数据版本；不可把客户端传入金币作为可信结果。多租户 SaaS 后台和角色权限管理需在确定实际管理场景后再增加，当前仅保留用户数据隔离。

当前未包含的扩展是家装系统、后台定时触发的微信订阅提醒，以及正式商业化所需的服务端权威经济结算。
